# استوديو آفاق — صانع شورتس القرآن

موقع لصناعة فيديوهات شورتس قرآنية عمودية (1080×1920) لقناة «آفاق» من المتصفح مباشرة:
اختر السورة والآية والقارئ والخلفية، عاين الفيديو، ثم صدّره جاهزًا للرفع على يوتيوب — مع توليد تلقائي للعنوان والوصف والهاشتاجات.

- نصوص الآيات: api.alquran.cloud (الرسم العثماني)
- التلاوات: everyayah.com
